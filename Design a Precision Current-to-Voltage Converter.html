Op-Amp Based Peak Detector

Learning Module • Circuit Design • Working Principle • Equations • Practice Quiz

1. Introduction

A peak detector is an electronic circuit that detects and stores the maximum value reached by an input signal. In a positive peak detector, the circuit stores the highest positive input voltage. An op-amp based precision peak detector uses feedback to reduce the error caused by the diode's forward-voltage drop.

Learning objectives

  • Identify the function of each component.
  • Explain tracking, holding and discharging.
  • Calculate the RC time constant.
  • Recognize the expected input and output waveforms.

Key terms

  • Tracking: capacitor voltage rises with a new higher peak.
  • Hold: stored voltage remains after input falls.
  • Droop: gradual reduction of stored voltage.
  • Reset: intentional discharge before a new measurement.

3. Working Principle

  1. Initial condition: The hold capacitor is discharged, so its voltage is approximately 0 V.
  2. Input rises: When the input rises above the voltage already stored on the capacitor, the op-amp drives the diode into conduction.
  3. Tracking: Current charges the capacitor, raising its voltage toward the new positive input peak.
  4. Input falls: The diode turns off and isolates the capacitor from the falling input signal.
  5. Hold: The capacitor retains approximately the highest positive voltage reached.
  6. Droop/reset: Leakage and the discharge resistor slowly reduce the voltage. A reset switch can discharge the capacitor before a new measurement.

4. Equations and Design Calculation

Ideal precision peak detector

Vout ≈ Vin,peak

Simple diode-capacitor detector

Vout ≈ Vin,peak − VF

Here, VF is the diode's forward voltage drop. The op-amp feedback in a precision topology compensates for much of this drop, within the op-amp's operating limits.

RC time constant

τ = RC

For R = 1 MΩ and C = 10 nF:

τ = (1 × 106)(10 × 10−9) = 0.01 s = 10 ms

For an ideal RC discharge, the voltage is:

V(t) = V0e−t/RC

The approximate droop rate due to an effective leakage current is:

|dV/dt| ≈ Ileak / C

5. Simulation Procedure (Multisim)

  1. Build the precision peak-detector circuit using the lab schematic and the selected op-amp model.
  2. Connect a sinusoidal input source and choose an amplitude and frequency suitable for the op-amp.
  3. Connect the oscilloscope's first channel to the input signal.
  4. Connect the second channel to the hold-capacitor/output node.
  5. Run the simulation and observe the two waveforms.
  6. Record the input peak and held output voltage, then compare them with the theoretical relationship.
Expected observation: The output rises when a new higher positive peak appears and stays nearly flat as the input falls. A small downward slope may occur because of leakage and the resistor discharge path.

No measured simulation values are stated here because the result depends on the exact circuit wiring, op-amp model, input amplitude and frequency.

6. Example Calculation

Question: A sinusoidal input has a positive peak of 4 V. Find the ideal held output voltage of a precision peak detector. Also calculate the RC time constant for R = 1 MΩ and C = 10 nF.

Solution:

Vout ≈ Vin,peak = 4 V
τ = RC = 1 × 106 × 10 × 10−9 = 10 ms

Answer: Ideal held output ≈ 4 V; time constant = 10 ms.

9. Viva / Interview Questions

  1. What is a peak detector?
    A circuit that stores the maximum positive or negative value reached by an input signal.
  2. What is the function of the capacitor?
    It stores charge representing the detected peak voltage.
  3. Why is an op-amp used?
    It helps compensate for the diode's forward-voltage drop in a precision design.
  4. What is droop?
    The gradual decrease of the held voltage due to leakage and loading.
  5. How is the detector reset?
    By using a switch or reset path to discharge the hold capacitor.

10. Result

An op-amp based positive peak detector detects and stores the maximum positive input voltage. The capacitor holds the detected peak, while the op-amp feedback reduces the error caused by the diode's forward-voltage drop. The RC time constant determines the approximate discharge behavior.
